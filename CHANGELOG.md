# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.19] - 2026-10-06

### Changed
- Product page: the "Ask on WhatsApp" button no longer sits in the buy box next to Add to Cart. On Luma it is shown below the product information and gallery, directly above the product tabs; on Hyva it is shown at the end of the product information card, below the buy box. The Solid, Outline and Text styles now render as a secondary button with its label (white, 1px #D4D4D4 border, 8px radius, 15px/600 text, 44px tall, 48px and full width below 768px) with the WhatsApp green kept only in the icon. The Icon Only style is a 44px round white button (48px below 768px). Button text, message template and settings are unchanged.
